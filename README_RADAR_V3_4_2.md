# Egonia Radar v3.4.2 — Telegram message template

The approved Telegram alert layout uses ALTCOIN RADAR, pair/exchange/event, price, 5m change (or 1m Live for an unfinished minute), relative volume, strength, #BASE #QUOTE hashtags, and closes with 🟢 BUY BASE/QUOTE or 🔴 SELL BASE/QUOTE. No extra Signal suffix. Numeric values come from the observed market event. No changes to the scanner, publishing policy, or credentials.

## Upgrade

Close the old bot, extract this FULL ZIP into a new folder, transfer your local `CREDENTIALS.cmd` (and optionally `signal_service.sqlite` while stopped), and run `START.bat`.
